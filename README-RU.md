# MetaGram Desktop

<img src="metagram/icon_preview.png" width="128" alt="MetaGram">

[ [English](README.md) | Русский ]

Клиент Telegram для компьютера с упором на приватность и настройку под себя.

## Возможности

- Режим призрака: без отметок о прочтении, скрытый статус «в сети» и «печатает»
- Сохранение удалённых сообщений
- История правок сообщений
- Настройка шрифта, внешнего вида и чатов
- Режим стримера, фильтры сообщений и многое другое

## Скачать

Сборки для Windows (x64) делает GitHub Actions: откройте вкладку
[Actions](https://github.com/ressedich/MetaGramDesktop/actions), выберите
последний успешный запуск **MetaGram Windows** и скачайте архив
**MetaGram-Windows-x64**. Программа портативная, установка не нужна.

## Сборка

Сборка для Windows описана в
[`.github/workflows/metagram-win.yml`](.github/workflows/metagram-win.yml).
Название в интерфейсе подставляет скрипт [`metagram/rebrand.py`](metagram/rebrand.py).
